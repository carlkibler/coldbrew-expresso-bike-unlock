# Model reports

One file per bike model, contributed by people (and their AI assistants) who
unlocked a model this repo hadn't documented yet. Each report says what was the
same, what was different, the exact steps that worked, and the raw probe output.

Paired with a machine profile in [`compat/profiles/`](../../compat/profiles/),
a report turns the next person's unlock from an investigation into one command.

**Adding one?** Follow Phase 6 of [`../agent-unlock-guide.md`](../agent-unlock-guide.md).
Name the file after the model or build string, e.g. `expresso-go.md`.

Documented so far: `20130123001` (2013 HD), `20180514001` (2018 HD).
